# Mobile UX Audit

Проверены 320–430 px, 768 и 1024 px; портретный сценарий практически. Альбомная ориентация и физические устройства не проверены.

## Что работает

- Bottom sheet сохраняет карту в контексте и открывается до 46vh, затем до `calc(100dvh - 128px)`.
- Свайп вверх/вниз и ручка предусмотрены (`src/main.ts:553-562`).
- Фильтры — отдельная нижняя панель с `safe-area-inset-bottom` (`src/style.css:195`).
- На 320–430 px горизонтальной прокрутки документа не найдено.
- Карточка квартиры читаема на 390 px; CTA остаются в одном экране после прокрутки.

## Проблемы

### MOB-001 — P1 — нет постоянной мобильной навигации

Нет нижнего меню «Карта / Поиск / Избранное / Сравнение». После углубления единственный возврат — текстовая кнопка в карточке или закрытие sheet.

**Исправление:** нижняя navigation bar 4 пункта, скрываемая только при вводе; состояния в URL/store. **Приёмка:** все четыре раздела доступны одним касанием, активный раздел имеет текст и иконку, цель ≥44×44 CSS px.

### MOB-002 — P2 — только два состояния bottom sheet

Реализованы 46vh и 88vh, компактного состояния с одной строкой ЖК нет. Закрытие свайпом вниз из среднего состояния легко спутать со скроллом.

**Исправление:** snap points 18/52/92%, drag only from handle/header, velocity threshold, `aria-expanded`. **Приёмка:** внутренний scroll не закрывает sheet; клавиатура не перекрывает активное поле.

### MOB-003 — P2 — перегруженная верхняя область

На 320 px topbar занимает около 116 px; дисклеймер конкурирует с картой и названием. Заголовок обрезается (`text-overflow`) до «3D-карта проектов…».

**Исправление:** сократить дисклеймер до badge «Демо» + раскрываемая информация; оставить название в одну строку. **Приёмка:** карта видна не менее чем на 70% высоты до открытия sheet.

### MOB-004 — P2 — шахматка не оптимизирована для пальца

Ячейки имеют `min-width:54px`, но вертикальный размер формируется двумя строками с `padding:4px`; часть целей меньше 44 px. Номер квартиры скрыт в `title`, недоступном на touch.

**Исправление:** карточка минимум 64×52 px с №, комнатами, площадью/ценой; sticky этаж; горизонтальная виртуализация по секции. **Приёмка:** номер и статус доступны без long-press, все цели ≥44×44.

### MOB-005 — P1 — системный Back не восстанавливает вложенное состояние

Используется `history.replaceState`, а квартира не получает собственный URL. Back может уйти с сайта вместо возврата «квартира → ЖК → карта».

**Исправление:** pushState для осмысленных уровней, сериализация `project/building/section/floor/apartment`. **Приёмка:** Android Back проходит уровни без потери фильтров и камеры.

## Рекомендованный мобильный путь

`Карта/список → компактная карточка ЖК → средняя карточка с вариантами → full-screen шахматка → квартира → sticky CTA`.

В режиме шахматки карта может быть свернута; на возврате необходимо восстановить этаж, секцию и scroll position. Основной сценарий должен оставаться доступным как список без 3D.
