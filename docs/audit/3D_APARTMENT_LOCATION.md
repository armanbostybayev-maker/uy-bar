# Расположение квартиры на здании

## Текущая реализация

При выборе квартиры вызывается `focusFloor(a.floor)` (`src/main.ts:421-429`). Функция проходит по **всем** зданиям ЖК и отмечает одинаковый номер этажа (`src/main.ts:323-345`). Карточка честно сообщает «Корпус / секция — нет в данных», поэтому показ не является положением квартиры.

[Desktop-доказательство: оранжевый этаж подсвечен на нескольких объёмах](screenshots/desktop-apartment.png).

## Критический вывод

Точное положение квартиры, её окна и вид нельзя вычислять из номера квартиры. До получения официальной топологии текущий режим необходимо назвать «Показать этаж (схематично)», а не «Показать квартиру на доме».

## Необходимая модель данных

```text
projectId → buildingId → sectionId → floorId → apartmentId
building: georeferenced model/footprint + north axis
floor: floor plate geometry + elevation
apartment: polygon/mesh + plan transform + window edges
source: provider, version, updatedAt, accuracy, approvedBy
```

Все три представления — каталог, шахматка и 3D — используют единый `apartmentId`. Геометрия проходит ручную проверку и имеет provenance.

## Этапы реализации

1. **Сейчас:** schematic floor highlight, явный badge «Схематично», скрыть утверждения об окнах конкретной квартиры.
2. **После CRM/планов:** связать квартиру с корпусом, секцией и floor plate; подсвечивать только один корпус/этаж.
3. **После BIM/GLTF:** apartment mesh, прозрачность остальных этажей, section cut, фасады и стороны света.
4. **После верификации окон:** направление окон и вид; показывать дату/источник и уровень точности.

## Двусторонняя синхронизация

- `selectedApartmentId` — единственный источник истины.
- Click в grid → camera target + building/section/floor/apartment highlight.
- Click по 3D mesh → карточка того же ID.
- Back из карточки → прежняя камера и scroll шахматки.
- При отсутствии mesh — fallback к этажу с предупреждением, без ложной точности.

## Критерии приёмки

- Выбор квартиры не подсвечивает другой корпус.
- Переключение 2D/3D не сбрасывает выбранный ID.
- Нет визуализации окна без подтверждённой геометрии.
- Keyboard/list fallback выполняет тот же сценарий без canvas.
- 3D asset имеет LOD, compressed texture/geometry и освобождается при смене ЖК.
