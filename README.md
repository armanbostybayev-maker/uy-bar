# Uy bar — 3D-карта проектов SVOYDOM в Астане (концепт-демо)

> **Концепт-демо для SVOYDOM. Не официальный сайт.** Данные с svoydom.kz на дату сборки (см. шапку сайта).
> Страницы закрыты от индексации (`noindex,nofollow`). Формы заявок ничего никуда не отправляют.
> Логотип и фирменные шрифты SVOYDOM не используются. Все кнопки «Купить» и «Подробнее» ведут на svoydom.kz.

## Быстрый старт
```bash
npm install
npm run dev          # http://localhost:5178
```

Тесты:
```bash
npm test            # unit (vitest): ипотека, URL-состояние, фильтры/сортировка, избранное/сравнение
npm run build       # данные → validate-data → tsc → vite
npm run test:e2e    # Playwright против собранного dist (vite preview :5179), установленный Chrome
npm run test:all    # всё вместе
npm run test:e2e:update   # пересоздать эталоны визуальных снимков
```
E2E: `tests/e2e/`:
- `core`: путь списком и клавиатурой, Back/Forward/refresh, ошибки API;
- `features`: ипотека, поиск, избранное, сравнение;
- `map`: перетаскивание во все стороны, Shift+drag, колесо, флажки, цвета, камера;
- `mobile`: нижняя навигация, шторка 18/52/92 %, жесты, touch pan/pinch через CDP;
- `widths`: 320–1920 px, 200 %, reduced motion;
- `visual`: снимки в режиме без 3D, внешние фото замаскированы.

Тестам карты нужен WebGL (SwiftShader) и сеть до tiles.openfreemap.org. Без них эти тесты пропускаются, а не падают. HTML-отчёт: `test-results/html`.

Обновить данные и собрать сайт (сборка падает, если `validate-data` нашёл ошибку в данных):
```bash
npm run update      # = scrape + build, результат в dist/ (работает и в Windows PowerShell 5.1)
```
`SCRAPE_CONTACT="you@example.com" npm run scrape` добавит ваш контакт в User-Agent. Без переменной он не передаётся.
`REFRESH=1` скачивает страницы заново. По умолчанию всё берётся из кэша `data/raw/`.

## Конвейер данных
| Шаг | Скрипт | Источник | Результат |
|---|---|---|---|
| 1 | `scripts/scrape/run.mjs` | svoydom.kz: `/projects/astana/*`, где есть JSON `projects-data`; `/apartments/astana/` (`window.__APTS_DATA__`); страницы ЖК (`<apartments-filter :initial-apartments>`) | `data/projects.json`, `data/apartments.json`, `data/scrape-report.md` |
| 2 | `scripts/geo/geocode.mjs` | координаты из `projects-data` (их ставит сам SVOYDOM), проверка адреса через Nominatim (OSM) | `data/geo-check.json` |
| 3 | `scripts/geo/osm.mjs` | Overpass (OSM): контуры зданий рядом с ЖК и инфраструктура в радиусе 1,5 км | `data/footprints.json`, `data/pois.json` |
| 4 | `scripts/build-data.mjs` → `scripts/validate-data.mjs` | всё перечисленное выше + `data/overrides.json` | `public/data/*` (ЖК целиком, квартиры и район подгружаются по ЖК) |

**Правила сбора.** Соблюдается robots.txt: секция `*` разбирается по правилу самого длинного совпадения, поддерживаются `*` и `$`. Запросы идут не чаще одного в 2 с, Nominatim — не чаще одного в секунду. Каждый ответ кэшируется в `data/raw/` и повторно не скачивается. Картинки и планировки не копируются, хранятся только ссылки на сервер svoydom.kz. Данные 2GIS, Яндекса и gis.esaulet.kz не используются.

**Что закрыто и потому не используется.** Полные списки квартир отдают только `/apartments/ajax.php` (`Disallow`) и `/local/components/custom/apartments.filter/ajax.php?action=…` (`Disallow: /*action=`). Поэтому у ЖК, где больше 12 квартир, показаны только первые 12–18, опубликованные в HTML. Черновик запроса на выгрузку: `docs/request-to-svoydom.md`.

## Дополнительные слои
| Слой | Скрипт | Источник | Что хранится |
|---|---|---|---|
| Этажность, секции, подъезды | `scripts/scrape/site-facts.mjs` | текст страниц ЖК на svoydom.kz (из кэша, без новых запросов) | `data/site-facts.json` с цитатами-доказательствами. Геометрии корпусов на сайте нет: схема строится из N секций |
| POI: образование, медицина, магазины, парки | `scripts/geo/pois-city.mjs` | OpenStreetMap через Overpass (ODbL), один кэшируемый запрос | `public/data/poi-city.json`: 1049 объектов, кликабельны на карте |
| Преступность (тепловая карта, включается в «Слоях») | `scripts/geo/crime.mjs` | открытая ГИС КПСиСУ Генпрокуратуры РК: qamqor.gov.kz → «Карта преступности» → ArcGIS `gis.kgp.kz/…/KPSSU/crime/FeatureServer/1` (публично, без авторизации; robots.txt не задан) | `public/data/crime.json`: последние 12 месяцев, сетка 100 м. **Не сохраняются** номер дела, орган и точный адрес |

Атрибуция OSM обязательна по лицензии ODbL, поэтому она оставлена в виде компактной кнопки ⓘ на карте.

## Ручные правки: `data/overrides.json`
Эти правки важнее автоматических данных. Ключ — slug ЖК (последняя часть URL на svoydom.kz).
```json
{ "projects": { "aibat": { "coords": [71.369, 51.171], "floorsMax": 12,
    "footprints": [{ "name": "Корпус 1", "floors": 12, "ring": [[71.3688,51.1712],[71.3694,51.1712],[71.3694,51.1709],[71.3688,51.1709],[71.3688,51.1712]] }] } } }
```
Контуры удобнее обводить в **редакторе**: `/editor.html`. Выберите ЖК, кликами обведите корпус, укажите этажность и нажмите «Скачать». Полученный файл сохраните как `data/overrides.json` и выполните `npm run build`.

## Чего нет в данных (честно)
- **Корпус, секция и позиция на этаже** не указаны. Шахматка показывает «этаж × квартиры этого этажа». 3D-этажи подсвечиваются для всех корпусов ЖК: какой квартире какой корпус соответствует, неизвестно.
- **Статусы «бронь» и «продана»** на сайт не выводятся, там только свободные квартиры.
- **Полные списки квартир** есть лишь у ЖК, где их не больше 12 (Baiqadam, Gauhartas 1 и 2, Araily, Altyn Emel). У остальных — первые 12–18. Подробнее в `data/scrape-report.md`.
- **Контуры строящихся корпусов**: в OSM их почти нет. Там, где контура нет, нарисован **схематичный** блок с пометкой в интерфейсе. Его нужно заменить разметкой в редакторе или генпланом.
- **Окна (сторона света)** показываются только как ориентация фасадов корпуса. Куда выходят окна конкретной квартиры, без поэтажного плана неизвестно.
- **Ипотека**: пресеты «7-20-25» (7 %, 20 %, 25 лет) и «рыночная» (18,5 %, 20 %, 20 лет) ориентировочные, параметры можно менять.
- **Район**: данные OSM могут быть неполными. Время пешком считается по прямой ×1,3 при 80 м/мин, изохроны — круги, а не маршруты.

## Стек
Vite + TypeScript, MapLibre GL JS 4. Подложка — векторные тайлы [OpenFreeMap](https://openfreemap.org) (данные © OpenStreetMap, без ключа) с собственным светлым стилем (`src/style-map.ts`). Для концепта этого достаточно. В боевой версии стоит собрать свои тайлы Астаны через Planetiler: так не будет зависимости от чужого CDN и появится контроль над слоями.

## Структура
```
scripts/scrape   сбор с svoydom.kz (http.mjs — вежливый клиент с robots и кэшем)
scripts/geo      Nominatim-проверка, Overpass
scripts/build-data.mjs
src/             приложение (main.ts — карта и панели, geo.ts — этажи, mortgage.ts)
editor.html      редактор контуров
data/            сырые и нормализованные данные, overrides.json
docs/            разведка, письмо в SVOYDOM, питч, скриншоты
```
